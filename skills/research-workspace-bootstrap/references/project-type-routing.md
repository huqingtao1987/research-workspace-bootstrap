# Task-routed growth

Use this reference only when the task requires choosing sources or a durable artifact. Project categories guide judgment; they do not prescribe a directory tree.

## Source routing examples

| Task | Minimal starting sources | Expand when |
|---|---|---|
| Current project status or scientific question | PROJECT.md, relevant current working files, related knowledgebase project page | Existing sources conflict or lack needed detail |
| Local analysis | Relevant data inventory, analysis plan or code, outputs, concise logs | Reproducibility or troubleshooting requires provenance |
| Historical decision | Specific decision file or referenced history | The current record lacks rationale |
| Literature-supported interpretation | Zotero candidates and necessary full text | Coverage is insufficient |
| Novelty, current landscape, completeness | Zotero plus authoritative Web sources | Search scope or recency requires it |
| Manuscript passage | Manuscript and relevant figure or claim files | The requested change depends on broader evidence |

Never make a full-project, full-knowledgebase, full-raw, full-Zotero, or open-world scan the default.

## Artifact examples by active work

- Paper: claim-evidence.md, figure-plan.md, manuscript.md.
- Grant: grant-plan.md, grant-draft.md.
- Analysis: analysis-plan.md, data-inventory.md, analysis-task.md.
- Database or research resource: database-state.md, data-pipeline.md, release-plan.md.
- Collaboration: an existing handoff, scope, or responsibility file.

Create or update one only after it passes the persistence gate. Prefer an existing equivalent filename and location.

## Persistence decisions

### Exploration

Keep ordinary discussion, alternatives, and unconfirmed reasoning in conversation.

### Stable working conclusion

Persist locally when a conclusion is stable enough to be reused across conversations and there is a natural plan or state file for it.

### Active artifact production

Create or update a draft only when continuous production of a manuscript, grant, analysis plan, release plan, or similar deliverable has actually begun.

### Long-term scientific state change

Suggest knowledgebase promotion only when the change is stable, important, and belongs in the long-term project record. Never treat local persistence as automatic permission to update the knowledgebase.

## Domain cautions

- Sensitive or clinical work: confirm deidentification and access boundaries before content inspection.
- Omics or computational work: preserve sample definitions, environments, parameters, logs, and rerun paths when those artifacts become active.
- Literature work: preserve search date, source, and citation identity when the evidence changes a claim.
- Preliminary results: keep observation, interpretation, inference, hypothesis, planned work, and user-confirmed decision separate.
