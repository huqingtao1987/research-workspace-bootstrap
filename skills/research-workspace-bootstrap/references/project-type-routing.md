# 项目类型与模块选择

先选择一个组合：项目组合角色 + 工作类型。只加载真正有用的模块。

## 项目组合角色

### 旗舰项目

适合长期主线课题。需要完整的状态、证据、决策、阶段总结和里程碑规则，强调可复现与长期生长。

### 可靠收尾项目

适合已有较多结果、目标是稳定交付的课题。优先冻结范围、列出剩余缺口、设置完成标准和交付检查表。

### 战略资源项目

适合数据库、队列、样本资源或平台建设。优先记录数据字典、版本、访问边界、复用接口和维护责任。

### 协作项目

优先记录责任边界、交付接口、输入输出格式、决策权限、依赖和沟通节点。

### 一次性任务

使用精简结构：README、规则入口、当前状态、待办与阻塞。只有出现可复用结论或持续工作时才扩展完整层级。

## 工作类型

### 课题设计

增加：核心问题、可证伪假设、主要终点、备选解释、关键风险和最小可行分析。

### 生物信息或组学分析

增加：样本与分组口径、输入清单、软件环境、参数、随机性、日志、输出目录、质量控制和重跑方法。样本数有冲突时不得自行择一。

### 临床或敏感数据

增加：脱敏状态、最小必要读取、受控路径、禁止外发内容和汇总粒度。未确认脱敏前只做文件级清点。

### 文献检索与写作

增加：检索日期、数据库、检索式、纳排标准、引用键、证据等级和引用核验。优先项目资料，再知识库、Zotero、权威在线来源。

### 结果解释与阶段总结

增加：观察、方法限定、文献支持、假设、反证、决策和下一步验证；避免把相关性写成因果。

### 稿件或汇报交付

增加：目标读者、交付格式、主张到证据映射、图表来源、版本冻结点和提交前检查。
